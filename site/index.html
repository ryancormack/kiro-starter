kiro-starter

A personal "getting started" repo for Kiro CLI features — hooks, MCP servers, prompts/slash commands, custom agents, and code intelligence — kept as a baseline to copy into any new project, or to point Kiro at directly to try things out.

What's in here

Custom agents

work-finder, adr-writer, and gpt-review — scoped agent configs with their own tool trust boundaries.

Hooks

PreToolUse shell hooks that guard npm installs and enforce Conventional Commits, failing open by design.

MCP servers

Linear's remote MCP server, wired in for issue/project/team access via OAuth.

Code intelligence

Optional language servers for TypeScript, Python, Kotlin, Swift, and Smithy on top of built-in tree-sitter support.

Prompts / slash commands

The /commit command: reviews changes, splits them logically, and writes Conventional Commit messages.

Using this repo

Drop this repo's .kiro/ contents into another project (or symlink/copy individual pieces), or start kiro-cli chat from within this repo to try things out directly. See each section above for details on what's configured and why.
