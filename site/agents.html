Agents

Custom agents

Custom agents in .kiro/agents/ pair a config (*.json — name, tools, trust boundaries) with a system prompt (*.md). Switch to any of them with /agent <name>.

work-finder

Pulls the next ticket from the Linear backlog (via the Linear MCP server — see MCP servers), confirms it with you before starting, verifies the workspace is the right repo for the ticket, asks clarifying questions, gathers codebase context and writes a plan to ./docs/plans/{date}-{name}.md before implementing it on a branch named with the Linear ticket ID (e.g. feat/ENG-123-...).

Commits reference the ticket ID (validated by the conventional-commit-guard hook), and the PR it opens with gh pr create references the ticket in its description. Never merges — stops and hands back the PR URL.

Read-only tools (read, grep, glob, code, todo_list, Linear) are trusted by default; write and shell are scoped via toolsSettings to this workspace and to specific safe git/gh commands, but still prompt for approval since those are the highest-impact actions in the workflow. 

"toolsSettings": {
  "write": {
    "allowedPaths": ["./**"],
    "deniedPaths": ["./.env", "./.env.*", "./**/secrets/**", "./**/*.pem", "./**/*.key"]
  },
  "shell": {
    "allowedCommands": [
      "git status", "git branch", "git log", "git diff",
      "git checkout -b .*", "git add .*", "git commit -m .*",
      "git push -u origin .*", "gh pr create.*", "gh pr view.*", "gh repo view.*"
    ],
    "autoAllowReadonly": true
  }
}

Config: .kiro/agents/work-finder.json · Prompt: .kiro/agents/work-finder.md

adr-writer

Writes Architecture Decision Records to ./docs/adr/NNNN-title-slug.md (auto-numbered) using a lightweight ADR template: Status / Context / Decision / Consequences / Alternatives Considered. Runs on claude-sonnet-5.

Read-only tools (read, grep, glob, code) are trusted for researching context; write is auto-trusted only for ./docs/adr/*.md — writes anywhere else still prompt for approval, keeping the agent scoped to its one job. It does not implement code, run commands, or edit any other file. 

"toolsSettings": {
  "write": {
    "allowedPaths": ["./docs/adr/*.md"]
  }
}

Config: .kiro/agents/adr-writer.json · Prompt: .kiro/agents/adr-writer.md

gpt-review

A code review agent running on gpt-5.6-sol, useful as a second opinion from a different model family. Fully read-only (read, grep, glob, code, all trusted) — it reviews and reports, it doesn't edit anything.

Reviews diffs, files, or whatever you point it at, and is instructed to disagree with prior conclusions when warranted rather than rubber-stamp them — distinguishing blocking issues (bugs, security, broken tests) from non-blocking suggestions (style, minor readability).

Config: .kiro/agents/gpt-review.json · Prompt: .kiro/agents/gpt-review.md
