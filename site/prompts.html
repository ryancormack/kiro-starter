Prompts / slash commands

Local prompt files in .kiro/prompts/*.md become slash commands (filename minus .md = command name), invokable as /<name> or via /prompts.

/commit

Prepares and creates git commit(s) for the current working directory changes, following a precise, repeatable workflow:

  1. Branch check. Refuses to commit directly on main/master; offers to create a new branch instead.
  2. Inspect. Runs git status and git diff (and --staged if relevant), reading changed files rather than guessing from the diff alone.
  3. Group logically. Splits unrelated changes into separate commits, staging each group explicitly (never a blanket git add . when splitting).
  4. Write Conventional Commit messages for each group — type(scope)?: description, imperative and lowercase after the colon, with a body for extra context and a ! suffix for breaking changes.
  5. Commit each group. Message format is validated automatically by the conventional-commit-guard hook (see Hooks) — non-conforming messages get rejected and retried.
  6. Confirm. Shows git log --oneline and git status after committing. Does not push.

If there are no changes in the working directory, it says so and stops rather than committing nothing.
